## 🎯 Features
- **3-Round Quiz Arena**:
  - **Round 1 (Unit 3)**: Trees & Applications (BST, Huffman, Prefix Codes, Game Trees).
  - **Round 2 (Unit 4)**: Boolean Algebra (Duality, K-Maps, Quine-McCluskey, SOP/POS).
  - **Round 3 (Unit 5)**: Algebraic Structures (Groups, Cosets, Lagrange's Theorem, Permutations).
- **Interactive Mechanics**: 15s timer ring, 1 mark per question (45 total marks), instant textbook explanations, sound effects.
- **Real-Time Leaderboard**: Live Firestore scoreboard with top 3 podium and search.
- **Scorecard & Performance**: Print official scorecards and retake options.
